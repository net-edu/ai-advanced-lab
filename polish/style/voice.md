# 어체 규범

`content/` 안 문서가 지켜야 할 문체 기준입니다. 여기 없는 것은 규칙이 아닙니다 -
검수자는 이 문서, [korean-naturalness.md](korean-naturalness.md),
[checklist.md](checklist.md)에 적힌 것만 지적합니다.

## 적용 범위

- **대상:** `content/**/*.md` 의 산문.
- **대상 아님:** `polish/`·`.claude/` 의 하네스 파일, 저장소 루트 `README.md`,
  `sample_src/` 의 원본 자료. (하네스 지시서는 간결함이 우선이라 평어체로 씁니다.)

## 기준 어체 - 합니다체

문서 전체를 `-습니다`/`-합니다` 로 씁니다. 근거는 취향이 아니라 실측입니다.
`content/` 4쪽과 발행용 25쪽 모두 합니다체가 지배 어체입니다.

한 문서 안에서 어체가 갈리는 것이 가장 흔하고 가장 눈에 띄는 결함입니다.
문서마다 갈리는 것도 마찬가지입니다 - 독자는 사이트를 한 사람이 쓴 것처럼 읽습니다.

```
그렇다        →  그렇습니다
설정하면 된다  →  설정하면 됩니다
확인해 보자    →  확인해 보세요   (지시문은 -세요 를 씁니다)
```

## 어체 예외 - 기능이 다르면 어체도 다릅니다

아래는 어체 이탈이 아니라 **의도된 장치**입니다. 검수에서 지적하지 않고,
`measure.py` 도 어체 통계에서 제외합니다.

| 장치 | 예 | 왜 예외인가 |
|---|---|---|
| 서사 캡션 | `▶ *도구는 쥐었다. 그런데 무엇을 시킬지 정해야 한다.*` | 본문과 다른 목소리로 흐름을 짚는 장치입니다. 합니다체로 바꾸면 캡션이 본문에 묻힙니다. |
| 표 셀·리스트 항목의 명사구 | `| harness | 루프 - 다음에 무엇을 할까 |` | 표는 문장이 아니라 항목입니다. |
| 헤딩 | `## 하네스는 낡는다` | 제목은 문장 어체를 따르지 않습니다. |
| 코드·명령·출력 | `./pipeline deploy` | 원문 그대로여야 합니다. |
| 인용문 | `> 원문 인용` | 남의 말은 고치지 않습니다. |

## 문장

- **한 문장에 한 생각.** 120자를 넘으면 끊을 자리를 찾습니다.
- **능동으로.** 이중 피동(`되어집니다`, `보여집니다`)은 쓰지 않습니다.
- **군더더기 제거.** `~에 대해서`, `~을 진행합니다`, `~하도록 합니다` 는 대개 지울 수 있습니다.
- **지시는 지시답게.** 독자가 할 일은 `~하세요` 로 씁니다. `~하시기 바랍니다` 는 쓰지 않습니다.
- **독자 호칭 최소화.** `여러분` 은 쓰지 않습니다. 필요하면 `사용자` 로 씁니다.

문장의 자연스러움(명사 연쇄·주체 생략·의인화·비유·번역투)은
[korean-naturalness.md](korean-naturalness.md) 를 따릅니다.

## 쓰지 않는 표현

| 쓰지 않습니다 | 대신 |
|---|---|
| 반드시 ~해야 합니다 | ~하는 편이 좋습니다 / ~하세요 |
| 상기한 바와 같이 | 앞서 살펴본 대로 |
| ~되어집니다 · ~보여집니다 | ~됩니다 · ~보입니다 |
| ~에 대해서 알아보겠습니다 | (바로 본론으로) |
| ~을 진행합니다 | ~합니다 |
| 굉장히 · 매우 · 정말 (강조 부사) | (삭제하거나 수치로) |
| 문장부호로 쓰는 em dash(—) | 하이픈(-) |

## 첨삭 예시

### 어체가 갈린 경우

> 원문 - 하네스는 **"지금 모델이 못 하는 것"에 대한 가정**을 담는다. 그래서 모델이 좋아지면 그 가정이 낡습니다.

> 고침 - 하네스는 **"지금 모델이 못 하는 것"에 대한 가정**을 담습니다. 그래서 모델이 좋아지면 그 가정이 낡습니다.

### 군더더기와 이중 피동

> 원문 - 이 설정에 대해서는 빌드 시에 자동으로 적용되어지도록 처리가 진행됩니다.

> 고침 - 이 설정은 빌드할 때 자동으로 적용됩니다.

### 긴 문장

> 원문 - 하네스를 session · sandbox 와 분리해 갈아끼울 수 있게 만들면 모델이 바뀔 때마다 전체를 다시 만들지 않아도 되고 배포 주기도 짧아지며 실험 비용도 줄어듭니다.

> 고침 - 하네스를 session · sandbox 와 분리해 갈아끼울 수 있게 만듭니다. 그러면 모델이 바뀔 때 전체를 다시 만들지 않아도 됩니다. 배포 주기가 짧아지고 실험 비용도 줄어듭니다.
