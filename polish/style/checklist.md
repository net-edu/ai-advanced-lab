# 검수 체크리스트

`style-guardian` 이 문서 한 쪽을 검수할 때 쓰는 항목표입니다.
지적은 **원문 인용 → 대안 → 이유** 형식으로 씁니다.

## 0. 보호 구간 - 어떤 모드에서도 고치지 않습니다

아래는 검수 대상이 아니라 **금지 구역**입니다. `guard.py` 가 스냅샷과 대조해
기계로 판정하고, 어기면 사람 판단 없이 문서를 되돌립니다.

| 보호 대상 | 왜 |
|---|---|
| 코드 블록 (언어 태그 포함) | 실행되는 것은 원문이 정답입니다 |
| 인라인 코드 | 명령·경로·식별자입니다 |
| 링크·이미지·미디어 경로 | 파이프라인 링크 검사와 배포된 주소가 걸려 있습니다 |
| 산문의 숫자·버전·날짜 | 사실입니다. 문장을 다듬다 수치를 흘리면 문서가 거짓말을 합니다 |
| H1 제목 | 목차 자동 편입 시 페이지 제목의 출처입니다 |
| 헤딩 텍스트 | 앵커 링크가 걸립니다. 개선 모드에서만 승인받아 바꿉니다 |
| `!!! warning` · `danger` 의 경고 사실 | 경고는 밀도 규칙에서도 제외합니다 |
| 표의 데이터 셀 (숫자·코드·경로) | 위와 같습니다 |

> 규약이 필수 정보를 지우게 만들면 규약이 틀린 것입니다.
> 지적과 보호 구간이 충돌하면 **보호 구간이 이깁니다.**

## 1. 문체 항목

빈도 항목은 **하한이 아니라 범위**입니다. 모자란 것만큼 넘치는 것도 결함입니다.
"강조가 부족하다" 는 지적은 하지 않습니다.

| 항목 | 확인할 것 | 임계값 | 등급 |
|---|---|---|---|
| 기준 어체 | 지배 어체가 합니다체인가 | 아니면 위반 | Critical |
| 어체 혼재 | 한 문서 안에서 어체가 갈리는가 (캡션·표·헤딩 제외) | 혼재율 25% 초과 | Should |
| 미해소 마커 | `TODO:` · `[작성중]` · `(확인 필요)` 가 남았는가 | 1건 이상 | Critical |
| 용어 표기 | [glossary.md](glossary.md) 의 표준 표기를 따르는가 | 1건 이상 | Should |
| 리드 문단 | H1 다음 첫 블록이 문단인가 | 없으면 위반 | Should |
| 쓰지 않는 표현 | [voice.md](voice.md) 의 금지 표현이 있는가 | 1건 이상 | Should |
| 이중 피동·군더더기 | `되어집니다` · `~에 대해서` · `~을 진행합니다` | 1건 이상 | Should |
| 주어 생략 | 문장에 주어가 빠져 누가·무엇인지 불분명한가 | 1건 이상 | Should |
| 비유 선행 | 개념 서술에서 비유가 기술 용어보다 먼저 나오는가 | 1건 이상 | Should |
| 긴 문장 | 한 문장이 120자를 넘는가 | 문서당 3건 초과 | Nice |
| bold 과포화 | `**굵게**` 가 너무 잦은가 | 40어절당 1개 초과 | Nice |
| 나열식 문단 | 본문이 리스트로만 채워졌는가 | 리스트 줄 45% 초과 | Nice |
| 콜아웃 남발 | `!!!` 가 너무 잦은가 (**경고·위험은 세지 않음**) | 300어절당 1개 초과 | Nice |
| 헤딩 위계 | H2 다음 H4 처럼 건너뛰었는가 | 1건 이상 | Nice |

수치는 `python3 polish/tools/measure.py --detail <파일>` 로 확인합니다.
**측정값은 지적의 근거일 뿐 지적 자체가 아닙니다** - 어떤 항목도 수치만으로
고치라고 하지 않습니다. 문장을 읽고 실제로 나쁜지 판단합니다.

## 2. 등급

| 등급 | 뜻 | 처리 |
|---|---|---|
| **Critical** | 기준 어체 이탈, 미해소 마커 | 반드시 고칩니다 |
| **Should** | 흔들리는 지점 | 고치는 편이 좋습니다. 필자가 거부하면 존중합니다 |
| **Nice** | 사소한 윤문 | 여유가 있을 때만 |

## 3. 과교정 방지

- 문서 한 쪽당 지적은 **5~10건**까지입니다. 전부 고치라고 하면 원저자의 목소리가 사라집니다.
- 같은 패턴이 반복되면 **하나로 묶어** 보고합니다 - "이중 피동 4회, 전반 점검 필요".
- 원저자의 의도된 변주(리듬·강조·캡션)는 인정합니다.
- 3회 왕복에도 합의가 안 되면 **원문을 채택**하고 [log.md](../log.md)에 "합의 실패"로 남깁니다.
  단 Critical 은 예외입니다 - 어체 이탈과 마커는 재량 대상이 아닙니다.

## 4. 기능이 다르면 따로 셉니다

같은 형태라도 하는 일이 다르면 다른 규칙을 적용합니다. 상한을 기계적으로 맞추려다
꼭 필요한 것을 지우게 되기 때문입니다.

| 같은 형태 | 다른 기능 | 규칙 |
|---|---|---|
| `!!! warning` | 데이터 손실·배포 사고 경고 | 밀도 상한 **없음** |
| `!!! info` · `tip` · `note` | 부연·팁 | 300어절당 1개 |
| `**굵게**` | 용어 첫 등장·경고 | 상한 계산에서 뺍니다 |
| `**굵게**` | 강조 | 40어절당 1개 |
