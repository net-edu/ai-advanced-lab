# 용어 표기

`measure.py` 가 이 표를 그대로 읽어 검사합니다. 규칙을 문서와 도구 두 곳에 두지
않으려고 한 파일로 합쳤습니다. 표 형식(`| 표준 표기 | 쓰지 않는 표기 | 비고 |`)을
지켜 주세요.

검사 대상은 **산문**뿐입니다. 코드 블록, 인라인 코드(`` `hook` ``), 링크 주소 안의
같은 낱말은 세지 않습니다 - 명령·식별자는 원문이 정답이기 때문입니다.

| 표준 표기 | 쓰지 않는 표기 | 비고 |
|---|---|---|
| 디렉터리 | 디렉토리 | 국립국어원 외래어 표기 |
| 저장소 | 리포지토리, 레포지토리, 레포 | 제품명 `Repository` 는 예외 |
| 사용자 | 유저 | |
| 명령 | 커맨드 | |
| 갱신 | 업데이트 | 제품 기능명이면 예외 |
| 에이전트 | 에이젼트 | |
| 서브에이전트 | 서브 에이전트 | 띄어 쓰지 않습니다 |
| GitHub | Github, 깃허브 | |
| MkDocs | Mkdocs, mkdocs | 명령·패키지명은 코드로 적으므로 예외 |
| 마크다운 | 마크다운문법 | 제품명·확장자는 원표기 |
| 미리보기 | 프리뷰 | |
| 배포 | 디플로이 | |

## 영문 용어를 언제 한글로 쓸지

`harness` · `context` · `skill` · `hook` 처럼 영문과 한글 표기가 섞여 있는 낱말이
있습니다. 현재 규칙은 이렇습니다.

- **산문에서는 한글**로 씁니다 - 하네스, 컨텍스트, 스킬, 훅.
- **첫 등장 한 번만** 영문을 병기합니다 - `하네스(harness)`.
- **코드·명령·고유명사**는 원표기 그대로 둡니다 - `harness engineering` 이 문서의
  제목이면 제목은 건드리지 않습니다.

이 규칙은 아직 강제하지 않습니다. 표에 넣기 전에 실제 문서에서 오탐이 얼마나
나는지 한 파를 돌려 보고 [active.md](active.md)에 판정을 남긴 뒤 옮깁니다.
