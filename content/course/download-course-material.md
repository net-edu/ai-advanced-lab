# 실습 자료 다운로드

이 문서는 사외 참가자가 공개 인터넷에서 실습 자료를 받는 방법을 안내합니다.

## 전제 조건

- 공개 GitHub 계정 또는 운영자가 안내한 공개 다운로드 링크
- 저장소를 내려받을 경우 Git 또는 GitHub Desktop

## 단계

1. 운영자가 제공한 공개 자료 페이지를 엽니다.

    [실습 자료 받기 →](https://github.com/net-edu/ai-ad-lab-exercise-material){ .md-button .md-button--primary }

2. Release 자산이 제공되면 ZIP 파일을 내려받아 압축을 풉니다.

3. 저장소로 제공되면 아래처럼 clone합니다.

    ```bash
    git clone <PUBLIC_MATERIALS_GIT_URL>
    ```

4. 다운로드한 폴더의 README에 적힌 준비 명령을 실행합니다.
