# 마크다운 기초

마크다운은 글자 몇 개로 제목·목록·링크를 표시하는 가벼운 문법입니다.

CLAUDE.md, 위키 페이지, 이 교안까지 모두 마크다운으로 씁니다.

아래 표로 문법을 익히세요. 그런 다음 에디터에 직접 쳐 보며 오른쪽 미리보기로 결과를 확인하세요.

## 자주 쓰는 문법

| 쓰고 싶은 것 | 마크다운 |
|---|---|
| 제목 | `# 제목`, `## 소제목` (`#` 개수로 단계) |
| 굵게 / 기울임 | `**굵게**`, `*기울임*` |
| 순서 없는 목록 | `- 항목` |
| 순서 있는 목록 | `1. 항목` |
| 링크 | `[보이는 글자](https://주소)` |
| 인용 | `> 인용문` |
| 인라인 코드 | `` `코드` `` |
| 코드블록 | 백틱 세 개로 위아래를 감쌉니다 |

## 직접 해보기

보며 어떻게 바뀌는지 확인하세요.
